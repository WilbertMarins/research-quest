# Research Quest Web

Frontend Next.js responsável por upload, criação e acompanhamento de tarefas, histórico, respostas e fontes.

## Desenvolvimento local

```bash
npm install
npm run dev
```

Execute os comandos dentro de `apps/web`. A aplicação fica disponível em `http://localhost:3000`.

O teste de componente está em `src/app/page.test.tsx`, mas não é executado automaticamente neste fluxo.
